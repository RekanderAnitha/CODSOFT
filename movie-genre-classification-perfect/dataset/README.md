# Dataset

Download the IMDb Genre Classification dataset from Kaggle:

https://www.kaggle.com/datasets/hijest/genre-classification-dataset-imdb

Place the Kaggle training file here as one of the following:

- `dataset/train_data.txt`
- `dataset/Genre Classification Dataset/train_data.txt`
- Any `.csv` file with `genre` and `description`/`plot`/`summary` columns

The included `sample_movies.csv` is only for smoke testing the pipeline and Streamlit app. Train with the Kaggle dataset for real results.
